# Support

For usage questions and reproducible bugs, open an issue at:

https://github.com/battle-doll/code-ontology-companion/issues

Before filing:

1. Remove private source, credentials, absolute paths, and ontology artifacts.
2. Reproduce with a minimal synthetic Java or Python example when possible.
3. Include the plugin version, Python version, operating system, command name, and sanitized error.

Do not post confidential repositories or security vulnerabilities in public issues. Follow [SECURITY.md](SECURITY.md) for vulnerabilities.
