# サポート

[English](../../SUPPORT.md) | [한국어](../ko/SUPPORT.md) | [日本語](SUPPORT.md) | [简体中文](../zh-CN/SUPPORT.md)

使用方法に関する質問や再現可能なバグについては、次の場所で issue を作成してください。

https://github.com/battle-doll/code-ontology-companion/issues

報告する前に、次を実施してください。

1. 非公開ソース、認証情報、絶対パス、オントロジー成果物を削除します。
2. 可能であれば、最小限の合成 Java または Python の例で再現します。
3. プラグインのバージョン、Python のバージョン、オペレーティングシステム、コマンド名、サニタイズ済みのエラーを記載します。

機密リポジトリやセキュリティ脆弱性を公開 issue に投稿しないでください。脆弱性については [SECURITY.md](SECURITY.md) に従ってください。
