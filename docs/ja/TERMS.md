Code Ontology Companion は現状有姿で提供され、正確性、完全性、商品性、特定目的への適合性、
セキュリティ、または権利非侵害について、いかなる保証も行いません。

バージョン 0.5.2 は、権限を有する Java／Spring および Python リポジトリ向けに、
ローカル静的解析、不変スナップショット、RDF、リネージュ、HTML ワークベンチ、
読み取り専用のローカル stdio MCP、および同意に基づく任意の Ollama エンリッチメントを提供します。

以下はユーザーの責任です。

- 自らが所有するか、調査する権限を付与されたリポジトリのみを解析すること
- ソースコードライセンス、秘密保持義務、プライバシー法、雇用契約、およびアクセスポリシーを遵守すること
- 成果物の保存場所を選択し、保護すること
- 検出結果に依拠する前に確認すること
- 使用を選択した、別途管理されるローカル Ollama インストールについて、セキュリティ、
  ネットワーク、保持、ライセンス、リソース使用量、およびモデルの挙動を確認し、管理すること
- 実行時の挙動を独立して検証すること

静的グラフは、リフレクション、生成コード、依存性注入、フレームワーク設定、動的ディスパッチ、
またはメタプログラミングに関連する関係を欠落させたり、誤分類したりする場合があります。
これは、セキュリティ監査、法的見解、実行時トレース、脆弱性に関する判定、
または安全な変更の保証ではありません。

任意のローカルモデルによる提案は、未検証の `inferred` エビデンスです。スキーマ検証、信頼度の数値、
反復、またはローカル実行によって、提案が観測済み、正確、安全、検証済み、または承認済みになることはありません。

本プラグインを、不正アクセス、機密データの持ち出し、セキュリティ管理の回避、第三者の権利侵害、
または提携もしくは推奨関係についての虚偽表示に使用してはなりません。

ソースは Apache-2.0 の下でライセンスされています。本規約はプラグインのサービス／ワークフローの
利用に適用され、そのソフトウェアライセンスによって付与される権利を制限するものではありません。

本プロジェクトは独立したプロジェクトであり、OpenAI、Broadcom、VMware、Spring project、Oracle、
または Python Software Foundation との提携関係はなく、これらによる推奨も受けていません。
