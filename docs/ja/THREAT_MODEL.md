## 対象範囲と保護資産

Code Ontology Companion は、明示的に選択・許可されたローカル入力を静的解析します。対象アプリケーションを import・ビルド・テスト・実行しません。自身の同梱ヘルパーと選択した Python/Node ランタイムは、別の信頼対象コンポーネントです。

保護資産には、ソース構造と業務知識、明示的な出現箇所の許可で保持した原文、不変スナップショットと来歴、非公開ワークスペースのパス、アクセス・レビュー記録、保護プロファイル、任意の推論サイドカーが含まれます。ソースファイル全体をコピーしなくても、これらのローカル成果物は機密情報になり得ます。

## 信頼とアクセスの境界

ファイル名・シンボル・コメント・リテラル・注釈・解析エラー・生成知識は信頼できないデータです。ソース文やレビュー済み知識の主張は、エージェントへの指示ではありません。ローカル解析の許可、アクセス権、業務レビュー、実行承認、公開共有の許可は別です。

許可された CLI 操作が選択したローカルワークスペースを管理します。Stdio MCP は登録済みワークスペースを読み、初期化・更新・削除・アップロードしません。主体の別名はローカルプロセスに結び付けられ、クエリ引数から役割を付与できません。これは OS アカウント内のアプリケーション境界であり、リモート本人確認やテナント分離ではありません。

AI ホストは許可された CLI/MCP 結果を自身の提供者へ処理・転送できます。ローカル解析の許可はその転送を許可しません。任意の Ollama 補強は別途同意を得て、固定 loopback 接続先と制限された移植用メタデータを使用し、`inferred` 結果を観測根拠から分離します。

## 脅威と対策

| 脅威 | 実装された境界 |
| --- | --- |
| プロンプト・HTML 注入 | 静的解析は対象を実行せず、スキーマ検査と出力エスケープで保持したソース由来内容をデータとして扱います。レビューは信頼できる指示への変換ではありません。 |
| 範囲の黙示的な欠落 | 選択一覧は解析・除外・未対応・失敗・ブロックの結果を保持します。走査制限やアクセス不能で分母が `UNKNOWN` になり得ます。機密に見えるコードファイル名だけで黙って除外しません。 |
| リンク・パス逸脱・特殊ファイル | 包含関係の検査、リンク・再解析ポイントの拒否、通常ファイルの読み取り、ソース・ワークスペース・出力の分離でアクセスを制限します。危険・利用不能な項目は未完了です。 |
| 読み取り中のソース・成果物差し替え | ファイル識別子・ハッシュ・制限付きディスクリプター読み取り・前後検査で選択データを結び付けます。パスとハンドルの各メタデータ提供元の変更検査を維持します。 |
| 個人識別子・登録秘密値の出力 | 設定済み非公開 HMAC-SHA256 プロファイルと対応パターン検査が保護対象を拒否します。管理者承認や出現箇所の許可でも検出済み拒否を上書きできません。 |
| 未許可の知識開示 | 現在の権限、選択したソース・業務スナップショットの固定値、レビュー・取消状態が読み取りと出力を制限します。方針専用投影は制限された根拠を伏せ、完全表示には追加権限が必要です。 |
| 古い知識・異なる入力の混在 | スナップショット・解析仕様・ダイジェストの結び付けで選択した不変入力を識別します。有効な過去スナップショットは現在のソースやアプリ動作を再確認した証拠ではありません。 |
| 生成完了を意味の完全性と誤認 | ステージング・検証・既存の宛先を置換しない公開・進捗と欠落数で保存完了と意味の完全性を分離します。正確な呼び出し・候補・未解決・`UNKNOWN` を区別します。 |
| リポジトリ変更・隠れた MCP 書き込み | 解析は対象データを読み、許可された状態変更は選択したローカルワークスペースと明示的に許可されたローカル登録情報・設定に限定します。公開 MCP 操作は読み取り専用です。 |
| 資源枯渇・転送の欠落 | ファイル・時間・レコード・バイト・出力の予算で処理を制限します。ページング・切り詰め・省略数と未処理境界を明示します。分割ワーカーの SQLite 上限はプロセス全体のメモリ保証ではありません。 |
| 人が使えない全データ画面 | 既定の人向け HTML は深さ 2、最大 3、初期表示は 32 ノード・64 集約エッジ・128 KiB データ以内です。選択表示のローカルチャンクを読み込みます。現在ページの検索と明示的なレコード/MCP 経路は範囲・権限が別です。 |
| 意図しないネットワーク開示 | 決定的解析とオフライン HTML は直接アップロードやテレメトリーを行いません。ホストによる転送と別途同意した `127.0.0.1:11434` 補強は別の受信者・境界です。 |

## Windows の公開とランタイム整合性

Windows 実装は祖先・親・ステージのハンドルを保持し、再解析ポイントを拒否して現在の非公開アクセスを検査します。既存の宛先を置換しないハンドル相対のネイティブ rename を使用します。同期ステージハンドルとネイティブの戻り値・状態の両方で完了を確認します。Windows パスの実行ビット・作成時刻を CRT ハンドルのメタデータと同一視せず、同一ファイルを結び付けながら各提供元内の完全なモード・時刻の前後検査を維持します。

予期しない pending やネイティブメモリ解放の失敗は公開成功ではなく `BLOCKED` です。実装はモジュール当たり最大 1 KiB の固定ネイティブ割り当て一つと関連ハンドルを保持し、削除処理と追加エクスポートを止め、新しいプロセスを要求します。不確実な成果物を自動削除せず、再起動だけで検証済みとも主張しません。公開エントリーポイントは閉じたランタイムにバイトコードを書き込まず、想定外の項目は引き続き拒否します。

## 残る制約

- シンボル・相対パス・構造化断片・許可された原文は機密の構造や方針を示し得ます。HMAC は知識全体を暗号化せず、人向け抽象化も共有許可ではありません。
- 制限付きテキスト・符号化検査は万能の DLP・OCR ではありません。未登録の人物・秘密値、バイナリ・画像メタデータ、第三者出力を検出できない場合があります。任意プロファイルがなければ実名保護は確認できません。
- 静的対応は有限です。リフレクション・生成コード・動的ディスパッチ・単位・業務意図・実行条件は未解決になり得ます。スキーマ/RDF の妥当性、根拠リンク、コマンド成功は方針の完全な意味や実行の証明ではありません。
- 同じ OS ユーザー権限のプロセスはローカルファイルにアクセスできます。ランタイム・ホスト・OS・アカウントの侵害は境界外です。Ollama メタデータはサービス・重みの認証やローカル実行の証拠ではなく、サービスの外部通信・保存を制御しません。
- 取消は後続の許可された読み取りを制限しますが、オフライン出力や独立した複製を遠隔回収できません。ローカル保存・削除は運用者が管理します。
- 障害耐久性はファイルシステム・環境ごとに異なり、パイプラインは Windows で `file_flush_only` を報告します。実際の挙動には対象環境のネイティブ検証が必要です。ABI モック・設定・他 OS のテスト成功は Windows 成功の確認になりません。

## 公開成果物と検証

配布前に、選択した実ソース・ZIP・掲載メタデータ/画像・選択した元コミットと提供者生成コミットの識別情報を検査します。非公開プロファイル・キー・ワークスペース成果物を公開パッケージに含めません。公開開発者別名は **battle-doll** です。manifest の別名やローカル Git 設定は提供者に保存された公開名の確認になりません。読めない履歴・提供者状態は `UNKNOWN` とし、保存内容の削除は確認なしに完了扱いしません。

パッケージ検査・ネイティブ回帰・アップロード・審査提出・承認・公開は別の根拠状態です。[プライバシーポリシー](PRIVACY.md)、[個人情報運用ガイド](PRIVACY_OPERATIONS.md)、[セキュリティ報告ガイド](SECURITY.md)を参照してください。
