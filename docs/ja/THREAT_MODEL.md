# 脅威モデル

[English](../../THREAT_MODEL.md) | [한국어](../ko/THREAT_MODEL.md) | [日本語](THREAT_MODEL.md) | [简体中文](../zh-CN/THREAT_MODEL.md)

## 資産

- 対象ソースとアーキテクチャ。
- ソースツリー付近の認証情報と設定。
- 対象リポジトリの完全性。
- 現在および過去のオントロジー、スナップショット、RDF、リネージュ、ワークベンチの完全性。
- 非公開ワークスペースパスとソースフィンガープリント。
- インストール、転送、バックグラウンド動作に対するユーザーの制御。
- オプションのローカル推論設定と inferred サイドカー。

## 信頼境界

アクセスが許可されている場合でも、リポジトリの内容は信頼されません。ファイル名、
シンボル、アノテーション、コメント、構文エラー、生成された成果物はデータであり、指示ではありません。

Codex がワークフローをオーケストレーションします。解析器は中核となるファイルシステム、
許可、出力、実行の境界を独立して適用します。ローカル MCP サーバーは 2 番目の境界です。
登録済みワークスペース ID だけを受け取り、読み取り専用メソッドを提供します。

オプションのローカル LLM ヘルパーは、意図的に分離された 3 番目の境界です。
決定論的解析や MCP から import されることはありません。同意前には、既知のインストール指標だけを
調べることができます。同意後には、1 つの固定 IPv4 ループバックエンドポイントに接続し、
選択されたワークスペース内だけに書き込むことができます。

## 脅威と緩和策

| 脅威 | 緩和策 |
| --- | --- |
| ソースまたは名前に含まれるプロンプトインジェクション | ソース本文、コメント、任意の文字列は保持しません。検証済みのドット区切りポリシー識別子はデータ専用グラフノードです。スキルでは、すべての識別子を信頼されないデータとして扱うことを要求します |
| シークレットの収集 | シークレットに似た名前／拡張子と、一般的な VCS、依存関係、生成物、キャッシュのパスを除外します |
| リンクまたはパスの逸脱 | リンクをたどりません。ルートのリンク／リパースポイントを拒否し、ワークスペースとスナップショットが境界内にあることを検証します |
| FIFO またはデバイスによるブロック | 通常ファイルだけを読み取り、特殊ファイルはスキップします |
| 対象コードの実行 | import、build、test、実行の経路はありません。パッケージチェックで対象コードの実行プリミティブを拒否します |
| リポジトリの変更 | ワークスペースはリポジトリ外に置く必要があり、リポジトリを内包できません。対象ダイジェストテストによって読み取り専用の動作を強制します |
| 不完全または破損した更新 | 更新前後の安定したマニフェスト、ステージング、検証、不変スナップショット、状態のアトミックな昇格を使用します |
| ソースの同時変更 | フィンガープリントが一致しない場合はステージング済み出力を隔離し、最終正常状態を保持します |
| MCP による任意ファイルアクセス | MCP はファイルシステムパスではなく、ランダムな登録済みワークスペース ID を受け付けます |
| MCP の隠れた書き込み | 公開されるすべての MCP ツールは読み取り専用であり、正確にアノテーションされています |
| 解析器または MCP によるネットワークへの流出 | 中核解析器、ワークスペース CLI、ワークベンチ、ランチャー、MCP にはネットワーククライアントがなく、待ち受けソケットを開きません |
| ローカル LLM への無断接続 | 指標検出は何も実行せず、どこにも接続しません。接続または書き込みが可能な probe、configure、enrich、disable には明示的な許可が必要です |
| エンドポイントのリダイレクトまたは LAN／公開ネットワークへの転送 | ヘルパーは `HTTPConnection("127.0.0.1", 11434)` だけを構築し、URL またはホストの入力を受け付けず、プロキシ設定を迂回し、リダイレクトをたどりません |
| リモート／クラウドの結果がローカル証拠として受け入れられる | `/api/tags`、`/api/show`、`/api/chat` から報告されるリモート／クラウドのマーカー、および digest／size／format／model 情報または completion 機能の欠落はフェイルクローズします |
| プロンプトインジェクションまたはモデル出力の捏造 | 制限された移植可能なメタデータだけを送信します。識別子は信頼されないデータであると宣言され、厳格な JSON、重複キー、有限数、ノード ID、役割、件数、サイズ、タイムアウトのチェックによって不正な形式の出力を拒否します |
| モデル推論が事実として昇格される | 正規化された結果は、権限がないことを示す厳密な宣言を伴う作成専用の `inferred` サイドカーであり、観測済みグラフ、RDF、リネージュ、MCP 出力に統合されることはありません |
| 非公開パスの開示 | 絶対パスと完全なフィンガープリントは、通常の RDF、HTML、MCP 出力から削除されます |
| リソース枯渇 | 対応拡張子のみを扱い、ファイル当たり 2 MiB とソース全体の上限、およびグラフ／影響／可視化／LLM ペイロード／応答の上限を設けます |
| HTML インジェクション | タイトルをエスケープし、JSON を安全に埋め込みます。CDN、iframe、リモートスクリプト、fetch は使用しません |
| 誤った因果関係の結論 | observed／declared／inferred／validated／approved の証拠を分離し、文書では実行時または因果関係に関する主張を禁止します |

## 残存リスク

- シンボルとリポジトリ相対パスから、機密アーキテクチャが明らかになる可能性があります。
- 変更されたリポジトリはバージョン 0.5.2 では全体が再解析されるため、
  CPU とメモリを顕著に消費する可能性があります。
- 静的解析では、リフレクション、生成コード、実行時条件、動的ディスパッチ、
  メタプログラミングを見逃す可能性があります。
- ローカルレジストリとワークスペースは、すでにユーザーのファイルシステム権限を持つ
  別プロセスに情報を開示します。
- 侵害された Python／Node ランタイム、Codex ホスト、オペレーティングシステム、
  ユーザーアカウントは、このプラグインのセキュリティ境界外です。
- ユーザーは作成後に成果物を意図的に共有できます。
- ループバックは Companion の送信先を制限しますが、別途管理される Ollama プロセスまたは
  モデルのネットワーク動作、ロギング、保持は制限しません。
- エンリッチメントは選択したモデルを実行し、CPU／GPU メモリを割り当てる場合があります。
  `keep_alive=0` は応答後の即時アンロードを要求しますが、別途管理されるサービスによる
  リソース解放を証明できません。
- Ollama API メタデータは自己申告です。`localMetadataVerified=true` はモデルの重みのバイト列を
  証明せず、ループバックサービスを認証せず、ローカル実行または外部通信がないことを証明しません。
  チャット応答のマーカーは、リクエストのメタデータがそのサービスに到達した後でのみ拒否できます。
- スキーマ検証後でも、モデルの提案が誤っていたり敵対的であったりする可能性があります。
  それらは未検証の推論のままであり、独立したレビューが必要です。

## セキュリティを変更する拡張

公開ネットワークエンドポイント、リモート AI 呼び出し、文書化された固定ループバックの
オプションのヘルパーを超える拡張、対象コードの実行、パッケージ／モデル／データベースの自動インストール、
認証、テレメトリ、常駐デーモン、ファイルシステムフック、書き込み可能な MCP ツール、
外部グラフストアには、新たなプライバシー、ライセンス、脅威モデル、提出内容のレビューが必要です。
