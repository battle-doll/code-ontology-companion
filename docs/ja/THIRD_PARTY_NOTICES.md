Code Ontology Companion 0.8.0 候補は Python 標準ライブラリとブラウザーの Canvas/DOM API を使用します。2D 表示の削除に伴い Cytoscape.js、ELK.js、web-worker の同梱を終了しました。Canvas2D は3D投影を描画する API であり、平面グラフのモードではありません。CDN、npm、ブラウザー worker は不要です。

RDF は W3C RDF、RDFS、XML Schema、PROV-O 名前空間を参照するだけで、その実装を同梱しません。ロゴとソースは本プロジェクトの資産です。互換性の説明に用いる製品名の第三者ロゴは同梱しません。
