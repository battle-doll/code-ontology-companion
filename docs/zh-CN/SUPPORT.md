# 支持

[English](../../SUPPORT.md) | [한국어](../ko/SUPPORT.md) | [日本語](../ja/SUPPORT.md) | [简体中文](SUPPORT.md)

如有使用问题或可复现的错误，请在以下地址创建 issue：

https://github.com/battle-doll/code-ontology-companion/issues

提交前：

1. 移除私有源代码、凭据、绝对路径和本体制品。
2. 尽可能使用最小的合成 Java 或 Python 示例复现。
3. 包含插件版本、Python 版本、操作系统、命令名称和经过清洗的错误信息。

请勿在公开 issue 中发布机密仓库或安全漏洞。漏洞请遵循 [SECURITY.md](SECURITY.md)。
