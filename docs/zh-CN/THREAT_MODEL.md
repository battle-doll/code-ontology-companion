## 范围与保护资产

Code Ontology Companion 对明确选择并获授权的本地输入进行静态分析，不导入、构建、测试或执行目标应用。插件自身的附带工具和所选 Python/Node 运行时是独立的可信组件。

保护资产包括源码结构与业务知识、经明确出现位置授权保留的原文、不可变快照与血缘、私有工作区路径、访问和审核记录、保护配置以及可选推理附加产物。即使未复制整个源文件，这些本地产物仍可能是机密。

## 信任与访问边界

文件名、符号、注释、字面量、注解、分析错误和生成知识都是不可信数据。源码语句或已审核知识声明不是给智能体的指令。本地分析许可、访问权限、业务审核、执行授权和公开分享许可彼此独立。

获授权的 CLI 操作管理所选本地工作区。Stdio MCP 只读取已注册工作区，不初始化、更新、删除或上传。主体别名绑定到本地进程，查询参数不能授予角色。这是 OS 账户内的应用边界，不是远程身份认证或租户隔离。

AI 宿主可能处理获准的 CLI/MCP 结果，或将其转发给自己的服务商。本地分析许可并不授权该传输。可选 Ollama 增强需单独同意，使用固定回环地址和有界可移植元数据，并将 `inferred` 结果与观测证据分开。

## 威胁与缓解措施

| 威胁 | 已实现的边界 |
| --- | --- |
| 提示词或 HTML 注入 | 静态分析不执行目标；结构检查和输出转义将保留的源码衍生内容作为数据。审核不会将其变为可信指令。 |
| 静默丢失范围 | 所选清单保留已分析、排除、不支持、失败和阻塞结果。遍历限制或访问失败可能使分母为 `UNKNOWN`；仅因代码文件名含敏感词不会静默移除。 |
| 链接、路径逃逸或特殊文件 | 包含关系检查、拒绝链接/重解析点、只读普通文件以及源码、工作区、输出分离限制访问。不安全或不可用项目保留为未完成。 |
| 读取中替换源码或产物 | 文件标识、哈希、有界描述符读取及前后检查绑定所选数据。路径和句柄元数据来源分别保留自身变化检查。 |
| 输出个人标识或登记秘密值 | 私有 HMAC-SHA256 配置和支持的模式检查拒绝受保护内容。管理员批准或出现位置许可不能覆盖已检测到的拒绝。 |
| 未授权知识披露 | 当前权限、所选源码/业务快照绑定、审核和撤销状态限制读取与导出。策略专用投影隐藏受限证据，完整视图需要更广权限。 |
| 过时或混合知识 | 快照、分析规格和摘要绑定标识所选不可变输入。有效历史快照不能证明已重新检查当前源码或应用行为。 |
| 将生成成功误认为语义完整 | 暂存、验证、不替换已有目标的发布、进度及遗漏数量区分存储完成与语义完整。精确调用、候选、未解析和 `UNKNOWN` 保持独立。 |
| 修改代码仓库或隐藏 MCP 写入 | 分析读取目标数据，获准状态变更仅写入所选本地工作区及明确授权的本地登记信息/配置。暴露的 MCP 操作保持只读。 |
| 资源耗尽或查询传输丢失 | 文件、时间、记录、字节和输出预算限制处理。分页、截断、遗漏数量及未处理边界明确保留。分片工作进程的 SQLite 上限不是整个进程内存保证。 |
| 人无法使用的全量浏览器视图 | 默认人用 HTML 深度为 2、最多 3，初始视图限制为 32 节点、64 聚合边和 128 KiB 数据。所选视图使用本地分块。当前页搜索与显式记录/MCP 路径具有不同范围和权限。 |
| 意外网络披露 | 确定性分析和离线 HTML 不直接上传或发送遥测。宿主转发和另行同意的 `127.0.0.1:11434` 增强属于不同接收方和边界。 |

## Windows 发布与运行时完整性

Windows 实现持有祖先、父目录和暂存目录句柄，拒绝重解析边界并检查当前私有访问权限。它使用基于句柄的相对原生 rename，不替换已有目标；同步暂存句柄、原生返回值与状态必须共同确认完成。绑定同一文件时，不将 Windows 路径的执行位或创建时间等同于 CRT 句柄元数据，同时保留每种来源内部完整的模式、时间前后检查。

意外 pending 或原生内存释放失败属于 `BLOCKED`，不是发布成功。实现每个模块最多保留一个不超过 1 KiB 的固定原生分配及关联句柄，阻止清理和后续导出，并要求新进程。它不会自动删除状态不明的产物，也不声称重启等于验证成功。公开入口不向封闭运行时写入字节码，意外运行时条目仍会被拒绝。

## 残余限制

- 符号、相对路径、结构化片段和获准原文可能泄露机密架构或策略。HMAC 不加密整个知识库，人用抽象视图也不是分享许可。
- 有界文本和编码检查并非通用 DLP 或 OCR。未知身份、未登记秘密、二进制/图片元数据及第三方输出仍可能漏检。缺少可选配置不能确认实名保护。
- 静态支持有限；反射、生成代码、动态派发、单位、业务意图及运行条件可能未解析。结构/RDF 有效、证据链接或命令成功不证明完整策略语义或实际执行。
- 具有相同 OS 用户权限的进程可访问本地文件。运行时、宿主、OS 或账户受损不在插件边界内。Ollama 元数据不认证服务或权重、不证明本地执行，也不控制该服务的外部网络与保留行为。
- 撤销约束后续授权读取，不能远程收回离线导出或独立副本。本地保留和删除由操作者管理。
- 故障耐久性因文件系统和平台而异；流水线在 Windows 报告 `file_flush_only`。实际平台行为需要原生验证；ABI 模拟、配置或其他 OS 的测试成功不能证明 Windows 成功。

## 公开产物与验证

分发前检查实际选定源码、ZIP、列表元数据/图像以及所选原始和服务商生成提交的身份信息。私有配置、密钥及工作区产物不得放入公开包。公开开发者别名为 **battle-doll**；manifest 别名或本地 Git 设置不能验证服务商保存的目录身份。不可读取的历史或服务商状态保持 `UNKNOWN`，未经确认不得声称保留内容已删除。

包检查、原生回归、上传、提交审核、批准和公开发布是不同证据状态。参见[隐私政策](PRIVACY.md)、[隐私操作指南](PRIVACY_OPERATIONS.md)及[安全报告指南](SECURITY.md)。

## 改变边界的扩展

添加远程端点/AI 调用、目标执行、自动依赖或模型安装、认证、遥测、常驻进程、文件系统钩子、可写 MCP 操作或外部知识存储前，应重新评估隐私、安全、许可与提交资格。
