生效/更新日期：**2026-10-30** · 版本 **0.9.3** · 开发者：**battle-doll**

Code Ontology Companion 对明确选择并获准的本地代码进行静态分析，不执行目标项目。本政策说明插件的本地数据处理；分析许可与披露、公开结果的许可相互独立。

## 本地读取和保留的数据

Java/Spring、Python、JavaScript/TypeScript、Bash 及其他语言有明确的支持级别，参见[实现指南](PIPELINE_0_9_0.md)。选择范围清单除已分析文件外，也保留未支持、排除、失败、阻止结果。不可访问或受限遍历可能使原始分母为 UNKNOWN。代码文件名带有类似秘密的词语，不会自动删除所选结构代码。危险路径、受保护的非源码格式、配置排除、资源限制均保留各自结果。

私有工作区可能保留：

- 所选路径、语言/支持标记、文件大小、源码哈希、位置范围、证据 ID、数量、警告、遗漏；
- 声明、关系、有界静态片段、条件 IR、支持的常量/schema 表达式、类型化输入、源码关联业务概念/属性；
- 业务声明、审核/撤销记录、源码/业务快照绑定、不可变分区 SQLite/JSON、RDF 投影及谱系；
- 本地运行所需的绝对源码位置、私有配置、访问策略、注册信息、缓存/恢复元数据、完整性资料。

这些是源码和策略数据，可能具有机密性。注释和带引号字面量默认不透明；但明确选择的私有字面量/文档审核或本地源码分析许可，可以为获准 occurrence 在本地保留精确原文。该许可不是业务含义批准、指令权限或公开许可；源码文字仍是不可信数据。即使没有复制整份源码文件，也不能把结构片段或获准原文视为匿名数据。

应用流程使用所选工作区、查询、修改路径及宿主观测的工具可用性，不自动存档对话历史。可选 Context、Contracts 属于单独授权流程。

## 保护和访问边界

`CODE_ONTOLOGY_PRIVACY_FILE` 指定私有 HMAC-SHA256 保护配置。密钥和登记指纹应保护在源码/输出根目录之外，不得打印、提交或导出。受支持检查拒绝配置的姓名/邮箱、登记保护值匹配，以及可识别危险模式。探测到的保护资料不能以管理员批准、别名、知识审核或本地 occurrence 许可绕过。

缺少或无效的必需导出配置会被拒绝。旧版普通本地探索路径可能允许可选配置；省略配置不意味着已保护真实姓名。有界文本/编码检查不是完整 DLP、OCR，也不保证发现全部未登记秘密、身份信息、二进制/图像或第三方输出。参见[隐私运维指南](PRIVACY_OPERATIONS.md)。

按请求的读取/导出检查当前源码/业务快照 pin、绑定、权限及保护状态。仅策略视图隐去受限源码证据和位置。完整记录/证据导出需要更广的读取权限及导出权限；明确投影的业务/策略 HTML 可在隐去受限证据的同时使用 `read_policy` 和 `export_html`。私有配置、访问设置、密钥不属于可移植知识产物。摘要视图不授予公开许可；后续 ACL 更改或撤销不能远程撤回已导出副本。

## 本地存储与用户控制

获准的 `analyze`/`refresh` 等操作 CLI 写入所选本地工作区、不可变快照历史及相关状态。旧快照保留至用户通过本地文件管理工具删除相应工作区/历史；可按需删除本地注册项。导出副本和 inferred sidecar 需另行删除。插件不提供用户数据托管服务或自动云备份。

本地 stdio MCP 工具只读注册工作区，不初始化、刷新、删除、上传知识，也不启动监听网络服务。用户可限制根目录/接收方、停止分析、拒绝导出/可选增强同意、检查产物并手动删除本地数据。审核/许可撤销作用于后续授权读取，不会删除独立保留的副本。

## 网络与其他接收方

确定性分析和生成的离线 HTML 不发送 telemetry，不直接通过网络上传。插件没有把安装用户私有工作区产物上传给开发者的功能。打开外部链接或分享导出内容与本地分析分开。

AI 宿主可能处理或转发所选视图允许的命令/MCP 结果，包括源码衍生文字和位置。分析许可不是传输许可。OpenAI 收到这些输出时，分别适用其[相关条款](https://openai.com/policies/terms-of-use/)和[隐私政策](https://openai.com/policies/privacy-policy/)；宿主和操作系统也有各提供方政策。

可选 Ollama 增强需要数据范围说明及明确同意。它使用已有的 `127.0.0.1:11434` 服务，发送符号名、完全限定名、相对路径、节点类型、观测关系等有界可移植元数据，不发送源码正文、注释、秘密、私有 manifest、原始文件哈希。它不发现任意 endpoint、不下载模型或启动 Ollama。私有状态可保存同意/模型元数据及与观测证据分离的规范化 `inferred` sidecar；helper 不保存原始 prompt/response。精确范围见[本地模型指南](references/local-llm.md)。

Ollama 报告的元数据检查不认证服务/模型权重，不证明本地推理或无外部连接。用户管理的服务/模型是独立接收方；Companion 无法控制其外部网络行为和保留方式。不信任该环境时请保持增强关闭。
