## 0.9.3 - 2026-10-28

Windows 使用相对于固定目录句柄且不覆盖目标的 native rename。路径与句柄 stat 通过文件身份关联，并保留各自的完整变更检查。发布完成状态未知时保留 native 内存及产物，并阻止该进程继续导出。 写入的产物将原始文件身份及精确字节绑定到关闭后的路径元数据，后续读取仍分别检查路径和句柄的变更。

公开 Python 入口不再向已验证的运行时目录写入字节码。验证编译使用独立的临时缓存，意外的运行时条目仍会被拒绝。

新增全范围 HTML/RDF 分片导出，核对源数据与业务知识的原始清单、生成时的完整性以及发布前的当前权限。保留普通预算和未完成状态，导出成功与语义完整性分别报告。

新增与证据绑定的 Java 算术、时间、异步 API 契约，enum 参数到字段的关联，以及非敏感策略字面量的私有精确位置审查。保留未解析状态、隐私拦截和源码变化后的失效处理。解释方法、审查输入及完整性限制见[质量改进流程](QUALITY_0_9_3.md)。

开发者：battle-doll。保留本地 MCP、供人阅读的离线 HTML、五种语言及 Windows、macOS、Linux 支持。

深层 JSON 字段可能使用 `companion.flat-json.v1`。通过有序 `nodes` 表及 `$ref` 还原 `root`，并验证 `originalSha256` 与 `sourceBinding`。记录 ID、证据和分页信息保持不变。这是无损传递，并非新分析或新权限。现有字节、节点、深度和隐私限制继续生效。

Java 声明保留泛型参数、注解、throws，以及头部、声明、主体的独立范围。类型引用提供原始文本、解析类型或 null，以及解析原因。即使唯一声明允许建立静态调用关系，未解析的类型信息仍会保留。歧义候选不计为精确调用，静态解析不能证明运行时的实现选择。

策略片段保留受支持语法的控制上下文与操作顺序。不透明字面量、未解析调用、运行时分派及未知单位保持显式标记。语法本身不能证明业务规则可执行、已批准或语义完整。

供人阅读的 HTML 通过 `data/` 共享分页原始记录，供五种语言共同使用。离线脚本提供易读的 JSON 视图与原始值搜索；脚本无法加载时仍可通过静态 JSON 链接查看。所有记录、来源固定信息、隐私检查与输出限制保持不变。请完整保存导出的文件夹。

新增与源码绑定的业务知识视图，表达带范围的概念、关系、类型化属性和审查历史。区分源码支持、操作者声明及批准，拒绝查询过期或已撤销知识。只读 MCP 显式固定源码和业务快照，供人阅读的 HTML 将此视图连接到现有代码地图。本地审查管理需要独立权限。加强发布边界及仅供证据查询的元数据保护。安全的 TypeScript 声明可与受支持的纯函数共存；声明数量与策略规则分别统计。RDF 语义片段记录实际提取器版本。

## 0.9.0 - 2026-10-23

- 添加有界本地数据流水线，提供不可变的分区SQLite快照、未变更文件事实复用、可恢复发布，以及无需重读源代码的固定快照读取。各文档语言层级使用保守的声明与导入适配器，明确部分覆盖和不支持范围，不提供完整编译器或全程序证明。已实现的执行配置为`workers=1`；配置限制不是实测容量。
- 添加静态Bash/POSIX shell函数、source引用、命令、流水线和控制流边界，以及保守的PowerShell声明与导入识别。不执行脚本或收集秘密参数；不输出引号或heredoc含糊的区域。
- 为6个领域候选添加类型化策略知识：Python支持已声明的布尔、整数和Decimal子集；Java与TypeScript支持显式类型的纯布尔条件函数。新增7个只读本地MCP工具用于封存流水线与策略查询，总数达到19个。策略问答使用已存储快照，不重读源代码；不支持的上下文和运行行为保持`UNKNOWN`，提取成功不代表业务批准。
- 添加默认仅授权所有者的私有知识访问，提供6项操作：`read_structure`、`read_policy`、`read_evidence`、`export_html`、`export_bundle`和`manage_access`。通过可信启动环境绑定主体，拒绝无效授权，在仅策略读取中隐藏源位置，并使用独立授权工作区划分保密边界。
- 生成五种语言的离线HTML，采用每页50条记录、精确证据锚点和有界的原有3D控件；保留RDF/PROV-O血缘，并提供排除源清单、缓存、访问策略和本地配置的私有可移植包。静态导出需要全部读取权限及相应导出权限，之后更改ACL不能收回已生成的副本。
- HTML和可移植导出必须使用私有身份拒绝配置，检查私有文件权限，并在失败、取消或输出预算耗尽时回滚不完整输出。保留本地MCP、人用离线HTML及Windows/macOS/Linux目标。开发者身份保持为`battle-doll`（배틀돌）；生成输出排除真实姓名和个人邮箱。
- 原生Windows执行、真实浏览器可用性和未实测的大规模容量仍未验证；单元测试不证明运行成功。此本地候选不会执行官方提交、批准或发布。
