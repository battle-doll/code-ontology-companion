> Информационный перевод. Юридически определяющим является английский оригинал.

Кандидат Code Ontology Companion 0.8.3 не включает сторонние библиотеки времени выполнения. Используются стандартная библиотека Python и браузерные API Canvas/DOM. После удаления плоского 2D-режима Cytoscape.js, ELK.js и web-worker больше не поставляются. Canvas2D рисует трёхмерную проекцию и не обозначает отдельный плоский режим графа. CDN, установка npm и браузерный worker не требуются.

Экспорт RDF ссылается на IRI пространств имён W3C RDF, RDFS, XML Schema и PROV-O; реализации этих стандартов в пакет не включены. Логотип и исходный код проекта — оригинальные материалы. Имена Java, Spring, Python, Apache Jena, RDF4J, GraphDB и Stardog описывают совместимость; сторонние логотипы не включены.

Независимые RDF/SHACL проверки разработчика могут использовать отдельно установленные средства проверки. Они не становятся обязательными зависимостями локального анализатора или содержимым пакета.

Необязательные инструменты разработчика RDFLib 7.1.4 и pySHACL 0.30.1 перечислены в `requirements-validation.txt` и предназначены только для проверки. Они не включены в архивы и не импортируются анализатором, MCP или HTML во время работы. Отдельный валидатор полного пакета требует явной установки оператором. Лицензионные уведомления этих зависимостей сохраняются в их собственных дистрибутивах.
