## 0.9.3 - 2026-10-28

Добавлен явный экспорт полного набора HTML/RDF частями с исходными списками кода и бизнес-знаний, проверкой целостности при создании и текущих прав перед публикацией. Обычные бюджеты и незавершённые состояния сохраняются; успешный экспорт не означает полноту семантики.

Добавлены связанные с доказательствами контракты арифметических, временных и асинхронных API Java, связи аргументов enum с полями и частная проверка точных вхождений несекретных литералов политик. Сохраняются неопределённость, запреты приватности и отмена проверки при изменении исходников. Интерпретация, входы проверки и границы полноты описаны в [цикле качества](QUALITY_0_9_3.md).

Разработчик: battle-doll. Сохраняются локальный MCP, автономный HTML для людей, пять языков, Windows, macOS и Linux.

Глубокие поля JSON могут использовать `companion.flat-json.v1`. Восстановите `root` по упорядоченным `nodes` и ссылкам `$ref`, проверьте `originalSha256` и `sourceBinding`. ID, доказательства и пагинация сохраняются. Это передача без потерь, а не новый анализ или разрешение. Ограничения байтов, узлов, глубины и приватности сохраняются.

Объявления Java сохраняют аргументы обобщённых типов, аннотации, throws и отдельные диапазоны заголовка, объявления и тела. Для каждого типа указываются исходная форма, разрешённый тип либо null и причина. Даже если уникальное объявление позволяет связать статический вызов, неразрешённые сведения о типах сохраняются. Неоднозначные кандидаты не считаются точными вызовами; статическое разрешение не доказывает выбор реализации во время исполнения.

Фрагменты политик сохраняют поддерживаемый контекст управления и порядок действий. Непрозрачные литералы, неизвестные вызовы, динамическая диспетчеризация и неизвестные единицы остаются явными. Синтаксис сам по себе не доказывает исполнимость, утверждение или полноту бизнес-правила.

HTML использует общие страницы исходных записей в `data/` для всех пяти языков. Автономный скрипт обеспечивает удобный просмотр JSON и поиск значений; при ошибке загрузки остаётся статическая ссылка на JSON. Все записи, привязки к исходнику, проверки приватности и ограничения объёма сохраняются. Храните всю экспортированную папку вместе.

Добавлено представление бизнес-знаний с привязкой к исходнику: понятия с явной областью, отношения, типизированные свойства и история проверок. Поддержка исходником, заявления оператора и одобрение разделены; устаревшие и отозванные знания не выдаются. MCP только для чтения требует явной фиксации исходного и бизнес-снимка, а HTML связывает это представление с прежней картой кода. Управление локальной проверкой требует отдельного разрешения. Усилены границы публикации и защита метаданных доказательств. Безопасные объявления TypeScript сохраняются рядом с поддерживаемыми чистыми функциями; объявления и правила политики учитываются отдельно. RDF-фрагменты семантики содержат фактическую версию экстрактора.

## 0.9.0 - 2026-10-23

- Добавлен ограниченный локальный конвейер данных с неизменяемыми секционированными снимками SQLite, повторным использованием фактов неизменённых файлов, восстанавливаемой публикацией и закреплённым чтением без повторного доступа к исходному коду. Консервативные адаптеры объявлений и импортов охватывают документированные уровни языков, явно указывая частичный охват и неподдерживаемые конструкции; они не предоставляют полный компилятор или доказательства для всей программы. Реализованный профиль выполнения — `workers=1`; заданные лимиты не являются измеренной ёмкостью.
- Добавлены статические функции Bash/POSIX shell, ссылки source, границы команд, конвейеров и потока управления, а также консервативное распознавание объявлений и импортов PowerShell. Скрипты не выполняются, секретные аргументы не собираются; неоднозначные области с кавычками или heredoc не выдаются.
- Добавлены типизированные знания о политиках для 6 кандидатов доменов: Python поддерживает заявленный фрагмент с логическими значениями, целыми числами и Decimal; Java и TypeScript — чистые функции логических условий с явными типами. Добавлены 7 локальных MCP-инструментов только для чтения запечатанного конвейера и политик, всего 19 инструментов. Вопросы о политиках используют сохранённые снимки без перечитывания исходного кода; неподдерживаемый контекст и поведение при выполнении остаются `UNKNOWN`, а извлечение не означает бизнес-одобрение.
- Добавлен частный доступ к знаниям, по умолчанию только для владельца, с 6 действиями: `read_structure`, `read_policy`, `read_evidence`, `export_html`, `export_bundle` и `manage_access`. Субъекты привязываются через доверенную среду запуска; неверные разрешения отклоняются, расположение исходного кода скрыто при чтении только политик, а для границ конфиденциальности используются отдельные разрешённые рабочие области.
- Генерируется автономный HTML на пяти языках со страницами по 50 записей, точными якорями оснований и ограниченными существующими элементами управления 3D; сохраняется происхождение RDF/PROV-O и предоставляется частный переносимый пакет без манифестов исходного кода, кэшей, политики доступа и локальной конфигурации. Статический экспорт требует всех разрешений чтения и соответствующего разрешения экспорта; последующие изменения ACL не отзывают уже сделанные копии.
- HTML и переносимый экспорт требуют частного профиля запрета персональных идентификаторов, проверяют права частных файлов и откатывают неполный результат при ошибке, отмене или исчерпании бюджета вывода. Сохранены локальный MCP, автономный HTML для людей и целевые Windows/macOS/Linux. Разработчик остаётся `battle-doll` (배틀돌); настоящие имена и личные адреса электронной почты исключаются из формируемых результатов.
- Выполнение на реальной Windows, удобство в настоящем браузере и неизмеренная крупномасштабная ёмкость остаются непроверенными; модульные тесты не доказывают эксплуатационный успех. Этот локальный кандидат не выполняет официальную отправку, одобрение или публикацию.

## 0.5.0 - 2026-08-13

- Добавлен необязательный интерактивный 3D constellation для той же ограниченной окрестности, что прежний 2D; тогда 2D оставался default/fallback. Общие выбор символа, ID, evidence, детали, фильтры и лимиты.
- Локальная проекция использует встроенный Canvas и данные `graph.html`; без CDN, пакета, WebGL, worker, telemetry/сети и обещаний graph database/SPARQL/runtime tracing.
- Добавлены pointer/keyboard orbit и zoom, reset, traversal, selection, return-to-root, reduced motion/forced colors, assistive status, hidden pause и безопасный переход в клавиатурный 2D при отказе Canvas.
- Визуализируется ограниченная выбранная окрестность, не весь репозиторий одновременно.
- Каждый emitted relationship получил `evidence` со стабильным `rule_id`, качественным `basis`, `runtime_status`, необязательными path/строками и ограниченными `limitations`; прежние тройки и ID сохранены.
- Опубликованы версионированный `document.quality` и матрица Java/Python adapter coverage для снимков/отчётов/query/HTML/MCP: supported/partial/heuristic/runtime_unknown не подменяются нулём warnings.
- Консервативно разрешаются Java-вызовы same-owner и распознанных импортированных типов; неоднозначность не создаёт выдуманного отношения.
- Golden/forbidden quality-gate проверяет ожидаемые/запрещённые узлы/отношения, evidence, coverage и детерминизм без исполнения цели.
- Сохранены stdlib без зависимостей, RDF-словарь, неизменяемость, отсутствие исполнения/сети и отдельно согласуемые inferred Ollama-sidecar.
