Этот каталог — русская точка входа в документацию Code Ontology Companion. Английские корневые документы являются определяющими оригиналами материалов о выпуске, безопасности, конфиденциальности, условиях, товарных знаках и сторонних уведомлениях. Русские, корейские, японские и китайские упрощённые переводы предназначены для удобства. Переводы юридических и политических документов информационные; при расхождении преимущество имеет английский оригинал.
