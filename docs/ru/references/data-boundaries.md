## Разрешённые входы

Анализируйте только локальный репозиторий, принадлежащий пользователю, администрируемый им или явно разрешённый для изучения. Путь от третьего лица не доказывает разрешение.

## Читаемые данные

Версия 0.8.3 читает обычные `.java` и `.py` размером до 2 MiB, с обязательными совокупными пределами количества файлов и байтов. Символические ссылки и Windows reparse points не разыменовываются. Каталоги зависимостей, VCS, генерируемого вывода, IDE, виртуальных сред и кешей пропускаются. Имена, указывающие на credentials, secrets, tokens, private keys, keystores или `.env`, исключаются даже с поддерживаемым расширением.

## Сохраняемые данные

Переносимые артефакты могут хранить имена символов/аннотаций, язык и типы узлов/связей, квалифицированные имена, проверенные точечные policy-ID распознанных Java-accessor, относительные пути и необязательные диапазоны строк, стабильные rule-ID, качественные основания, статус выполнения, ограничения/покрытие адаптеров, счётчики и предупреждения.

Закрытое пространство дополнительно хранит абсолютный путь репозитория для обновления, размеры и SHA-256 файлов, ID снимков/событий/пространства, необязательную Git-ревизию из обычных `.git`-метаданных. Закрытый `source-manifest.json`, записи восстановления и ключ кеша не входят в публичный манифест результатов. Кеш хранит подписанные операции графа без тел исходников; при непроверяемых правах используется полный разбор. Переносимые RDF, HTML и обычные ответы MCP намеренно не раскрывают абсолютный путь репозитория и полные отпечатки файлов.

HTML встраивает полный переносимый индекс узлов/рёбер для локального поиска и обычно рисует ограниченную окрестность. Кнопки добавления/удаления слоя раскрывают все области до выбранной накопленной глубины с сохранением предков. Каждый переход вверх к четвёртому и более глубокому слою требует подтверждения. Глубокие слои остаются свёрнутыми; одной команды раскрытия всего индекса нет. Такой режим всё же может расходовать значительные ресурсы и не восстанавливается из ссылки. Пространство раскладки растёт с содержимым; нижние кнопки масштабирования камеры независимы. Используются встроенные Canvas и DOM; CSP запрещает соединения и workers.

Большой проект хранит независимые модульные пространства и каталог с относительными ссылками на закреплённые снимки. Закрытая конфигурация родителя содержит путь репозитория и выбранные модули. Каталог содержит имена модулей, ID снимков, совокупные отпечатки и счётчики, но не тела кода или абсолютный путь. Графы не объединяются, межмодульные вызовы не выводятся; прежние ограничения каждого модуля сохраняются. Каталог и история остаются локальными без отдельного разрешения на передачу.

Наблюдаемые артефакты не предназначены для хранения тел кода, произвольных строк, комментариев, содержимого файлов, переменных окружения, учётных данных, API-ключей, токенов, промптов или ответов модели.

После явного включения локального LLM отдельная конфигурация хранит фиксированный endpoint, версии согласия/области данных, проверенные имя/digest/возможности модели. На POSIX действует `0600`, в Windows конфигурация LLM наследует ACL выбранного пространства; это отдельная граница от строгой проверки приватного identity-профиля. Успешный запуск создаёт sidecar с нормализованными ролями и уверенностью, происхождением снимка/модели/схемы, ограниченными digest входа/онтологии. Сырые промпты/ответы не сохраняются. `inferred` sidecar не объединяется с наблюдаемой онтологией/RDF/журналом/MCP.

Идентификаторы и относительные пути могут быть конфиденциальны. По умолчанию оставляйте артефакты локально; перед передачей нужно отдельное разрешение.

## Записи

`doctor` и `preflight` ничего не записывают. Инициализация создаёт явно выбранное новое пространство вне репозитория и не содержащее его. Обновление формирует и проверяет полный staged-снимок, затем атомарно переключает указатель с сохранением прежнего снимка. Журнал событий логически дополняется через атомарную замену; запись запуска позволяет `recover` восстановить прерванный шаг без дубликатов. `doctor --workspace` только проверяет состояние восстановления.

## Сеть и исполнение

Анализатор не обращается к сети и не импортирует, компилирует, собирает, тестирует или запускает целевой код. Пакеты, модели, базы, демоны и постоянные watchers не устанавливаются. Хост Codex может запустить читающий stdio MCP при включении плагина. MCP не слушает порт и не принимает произвольные пути; доступ ограничен пространствами, зарегистрированными после разрешённой инициализации.

После явного согласия для пространства отдельный помощник может обращаться только к существующему Ollama на `127.0.0.1:11434`. Произвольные endpoint, proxy, redirect, API-ключи и LAN/публичные адреса запрещены; remote/cloud-признаки и недостаточные метаданные отвергаются. Ограниченный payload может включать node-ID, имена символов/типов/аннотаций, квалифицированные имена, относительные пути и наблюдаемые связи. Тела кода, комментарии, произвольные строки, секреты, абсолютные пути, закрытые манифесты и сырые хеши исключены. Установки/скачивания модели и запуска сервиса нет. Обогащение исполняет выбранную модель, может занимать CPU/GPU и запрашивает выгрузку через `keep_alive=0`; сеть, ресурсы и хранение Ollama находятся вне контроля Companion.

Codex может обрабатывать вывод анализатора для запрошенной задачи по условиям и политике OpenAI. Версия 0.8.3 не вызывает удалённый сервис данных и не загружает артефакты сама.

## Интерпретация

Граф — статическое свидетельство структуры и близости изменений, а не доказательство выполнения, безопасности или причинности. Рефлексия, runtime bean-условия, генерируемые прокси, внешняя конфигурация, динамические импорты, monkey-patching, DI-контейнеры и генерируемый код могут менять фактическое поведение.
