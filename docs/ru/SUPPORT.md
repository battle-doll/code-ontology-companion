По вопросам использования и воспроизводимым ошибкам создайте issue:

https://github.com/battle-doll/code-ontology-companion/issues

Перед отправкой:

1. Удалите частный исходный код, учётные данные, абсолютные пути и артефакты онтологии.
2. По возможности воспроизведите проблему на минимальном синтетическом примере Java или Python.
3. Укажите версию плагина, Python, операционную систему, имя команды и обезличенную ошибку.

Не публикуйте конфиденциальные репозитории и сведения об уязвимостях в открытых issues. Для уязвимостей следуйте [политике безопасности](SECURITY.md).
