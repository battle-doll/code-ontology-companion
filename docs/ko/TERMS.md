Code Ontology Companion은 정확성, 완전성, 상품성, 특정 목적 적합성, 보안 또는 비침해에 대한 어떠한 보증이나 보장 없이 현 상태 그대로 제공됩니다.

귀하는 다음 사항을 책임집니다.

- 본인이 소유하거나 검사 권한이 있는 저장소만 분석
- source-code license, confidentiality duty, privacy law, employment agreement, access policy 준수
- artifact 위치 선택 및 보호
- 결과에 의존하기 전에 검토
- 사용하기로 선택한 별도 관리 local Ollama installation의 security, networking, retention, licensing, resource use, model behavior 검토 및 제어
- runtime-binding receipt를 사용할 때 정확한 baseline policy와 shadow condition 재검증
- runtime behavior를 독립적으로 검증

static graph는 reflection, generated code, dependency injection, framework configuration, dynamic dispatch, metaprogramming, unsupported language과 관련된 관계를 누락하거나 잘못 분류할 수 있습니다. security audit, legal opinion, runtime trace, vulnerability verdict, safe change guarantee가 아닙니다.

선택적 local model suggestion은 검증되지 않은 `inferred` evidence입니다. Schema validation, confidence number, repetition, local execution만으로 suggestion이 observed, correct, secure, validated, approved가 되지 않습니다.

`runtimeEffective=true`는 known supplied-policy shadowing이 없는 frozen active source snapshot의 static production-branch reachability만 뜻합니다. execution, order submission, policy safety, investment advice, trading authorization, 현재 또는 미래 profitability의 evidence가 아닙니다.

이 plugin을 unauthorized access 획득, confidential data exfiltration, security control 우회, third-party right 침해, affiliation 또는 endorsement 허위 표시 목적으로 사용할 수 없습니다.

source는 Apache-2.0에 따라 license됩니다. 본 약관은 plugin service/workflow의 사용을 규율하며 해당 software license가 부여한 권리를 축소하지 않습니다.
