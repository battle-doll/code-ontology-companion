[English](../../SUPPORT.md) | [한국어](SUPPORT.md) | [日本語](../ja/SUPPORT.md) | [简体中文](../zh-CN/SUPPORT.md)

사용 관련 질문과 재현 가능한 버그는 다음 주소에서 issue를 여십시오.

https://github.com/battle-doll/code-ontology-companion/issues

제출하기 전:

1. private source, credential, absolute path, ontology artifact를 제거합니다.
2. 가능하면 최소한의 synthetic Java 또는 Python 예제로 재현합니다.
3. plugin version, Python version, operating system, command name, 정제된 error를 포함합니다.

confidential repository나 security vulnerability를 public issue에 게시하지 마십시오. 취약점은 [SECURITY.md](SECURITY.md)를 따르십시오.
