일반 모드 · 레이어 추가/삭제는 모든 영역을 한 층씩 누적해서 펼치고 접습니다. 4단계 이상 추가할 때는 확인이 필요합니다. 상위 레이어를 유지하며 배치 공간과 확대율이 함께 바뀝니다. Shift + 드래그로 이동할 수 있습니다. 선택 영역 탐색은 특정 모듈만 펼칩니다. 호출 강조는 원본 정적 CALLS 관계를 따릅니다.

사용 안내

코드에서 근거까지

  1. 모듈을 선택해 펼치거나 위의 검색으로 심볼을 찾으세요.
  2. 항목 또는 선을 선택하면 상대 경로·줄 번호와 정적 관계 근거를 확인할 수 있습니다.
  3. 모든 심볼·원본 관계는 전체 탐색, 현재 화면의 항목은 목록 보기에서도 선택할 수 있습니다.

+·− 레이어는 모든 영역을 한 층씩 누적해서 펼치고 접습니다. 선택 영역 탐색은 선택한 모듈·구성요소만 펼칩니다. 4단계 이상 레이어를 추가할 때는 확인이 필요합니다.

드래그 또는 좌우 방향키로 회전하고 휠 또는 더하기와 빼기로 확대·축소합니다. 위아래 방향키로 심볼을 찾고 Enter 또는 Space로 선택합니다. F 또는 Home은 전체 화면, Escape는 이전 선택입니다. 전체 탐색에서 모든 원본 심볼과 관계를 페이지로 볼 수 있습니다. 위아래 방향키로 이동하면 선택한 거리까지 실제 CALLS 관계가 강조됩니다.
