# Third-Party Notices

Code Ontology Companion 0.1 bundles no third-party library, model weight,
database, font, telemetry SDK, or network service. Executable code uses only
the Python and Node.js standard libraries supplied by the user's environment or
supported Codex host.

The RDF exports reference W3C RDF, RDFS, XML Schema, and PROV-O namespace IRIs.
Referencing a public standard or namespace does not bundle its implementation.

The logo and source are original project assets released with this repository.

Java, Spring, Python, Apache Jena, RDF4J, GraphDB, and Stardog names appear only
to describe compatibility or migration targets. No third-party logo is bundled.
