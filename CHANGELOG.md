## 0.9.0 - 2026-10-23

- Add a bounded local data pipeline with immutable partitioned SQLite snapshots, unchanged-file fact reuse, recoverable publication and pinned source-free reads. Conservative declaration/import adapters cover the documented language tiers with explicit partial and unsupported coverage; they do not provide full compiler or whole-program proofs. `workers=1` is the implemented execution profile; configured limits are not measured capacity.
- Add static Bash/POSIX shell function, source-reference, command/pipeline and control-flow boundaries alongside conservative PowerShell declarations/imports. Do not execute scripts or collect secret arguments; withhold ambiguous quote/heredoc regions.
- Add typed policy knowledge for six domain candidates: Python supports the declared boolean/integer/Decimal fragment; Java and TypeScript support explicitly typed pure boolean condition functions. Add 7 read-only local MCP tools for sealed pipeline and policy queries, bringing the total to 19. Policy questions use stored snapshots without rereading source; unsupported context and runtime behavior remain `UNKNOWN`, and extraction is not business approval.
- Add private owner-default knowledge access with 6 actions: `read_structure`, `read_policy`, `read_evidence`, `export_html`, `export_bundle` and `manage_access`. Bind principals through the trusted launch environment, fail closed on invalid grants, withhold source locators from policy-only reads, and use separate authorized workspaces for confidentiality boundaries.
- Generate five-language offline HTML with 50-record pages, exact evidence anchors and bounded existing 3D controls; preserve RDF/PROV-O lineage and provide a private portable bundle excluding source manifests, caches, access policy and local configuration. Static exports require all read permissions plus their export permission and cannot be recalled by later ACL changes.
- Require a private identity-deny profile for HTML and portable export, check private file permissions, and roll back incomplete output on failure, cancellation or output-budget exhaustion. Preserve local MCP, offline human HTML and Windows/macOS/Linux targets. Developer identity remains `battle-doll` (배틀돌); real names and personal email are excluded from generated outputs.
- Native Windows execution, real-browser usability and unmeasured large-scale capacity remain unverified; unit tests do not establish operational success. This local candidate performs no official submission, approval or publication.
